# Get-DuoPassportConfig

## SYNOPSIS
Retrieve Passport Configuration

## SYNTAX

```
Get-DuoPassportConfig [<CommonParameters>]
```

## DESCRIPTION
Returns the current Duo Passport configuration. Requires "Grant resource - Read" API permission.

## EXAMPLES

### EXAMPLE 1
```
Get-DuoPassportConfig
```
